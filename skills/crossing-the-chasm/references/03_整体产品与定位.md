# 整体产品与定位

## 一、整体产品模型(Whole Product)
实用主义者买的不是你的产品，是"能让他达成目的的一整套东西"。差距越大，鸿沟越宽。
四层：
1. **通用产品**：合同里写的、装箱发货的那个东西。
2. **期望产品**：客户默认应该一起有的东西(安装、基本培训、能跟现有系统对接)。缺了客户觉得被骗。
3. **延伸产品**：让客户真正把它用起来、拿到承诺价值的配套(实施服务、行业模板、第三方集成、专业支持)。鸿沟期的战场在这层。
4. **潜在产品**：未来随着配套生态成长可能实现的东西。早期市场卖的是这层，主流市场不信这层。

鸿沟期规则：**给目标细分把延伸产品做齐，只给这一个细分做**。给所有人做整体产品是做不完的。

## 二、整体产品盘点表
对选定细分，从客户"迫切理由"倒推：客户要达成什么结果 → 需要哪些东西齐了才能达成 → 每一样谁来提供。

| 组件 | 是否必须 | 现状(有/缺/半成) | 自己做/找伙伴 | 伙伴是谁 | 伙伴图什么 | 期限 |
|---|---|---|---|---|---|---|

伙伴盘点原则：
1. 找的是**战术联盟**不是战略联盟。目的是把这一个细分的整体产品凑齐，不是签个大合作。
2. 伙伴必须在这笔生意里赚到钱，否则不会真投入。算清对方的账。
3. 优先找该细分里客户已经在用的服务商，他们自带参考效应。
4. 谁负责整体产品的"总装"要明确，通常是你自己，因为客户认的是你。

## 三、竞争集合：主动给自己造两个对手
实用主义者不在"没有对手"的市场里买东西，因为没对手等于没品类等于风险不可比较。
两个参照物：
1. **市场替代品**(Market Alternative)：目标客户现在为解决这个问题花钱给谁。作用：证明预算存在、问题真实。你的说法是"我们解决同一个问题，但用了新方法，所以效果好N倍"。
2. **产品替代品**(Product Alternative)：用类似新技术的同行。作用：证明这项技术是趋势。你的说法是"他们是通用的，我们是专门为你这个细分做的"。
选对手的原则：对手要真实、客户认识、且你能在该细分明确胜出。

## 四、定位罗盘(Positioning Compass)
定位是**在客户脑子里占一个位置**，不是你自己的口号。不同段的客户听不同的话：

| 段 | 关心的证据 | 有效的说服方式 | 无效的说法 |
|---|---|---|---|
| 技术狂 | 架构、性能、技术优越性 | 技术白皮书、基准测试 | 商业价值 |
| 有远见者 | 能否带来突破性业务成果 | 愿景、案例设想、创始人 | 稳妥、标准 |
| 实用主义者 | 谁在用、整体产品全不全、你是不是领导者 | 同行参考客户、行业分析师、行业媒体 | 技术领先、颠覆 |
| 保守主义者 | 便宜、可靠、一站式、服务 | 打包价、服务承诺、大规模案例 | 新功能 |

定位演进四阶段(随着市场推进逐级加码，不能跳)：
1. **命名与框定**：你是什么品类的什么东西。(给技术狂)
2. **给谁解决什么**：目标客户+痛点。(给有远见者)
3. **凭什么信你**：参考客户、伙伴、整体产品。(给实用主义者)
4. **凭什么选你**：市场领导者身份、性价比。(给保守主义者)
鸿沟期要打的是第2到第3阶段。

## 五、两句式定位陈述模板
```
给[目标客户]
他们[遇到的痛点/迫切理由]，
我们的[产品名]是一个[品类]，
能[关键收益/迫切理由的解法]。
不同于[产品替代品或市场替代品]，
我们[关键差异点，对该细分有意义的那个]。
```
写作要求：
1. 目标客户要具体到岗位+行业+规模档，写"企业"等于没写。
2. 品类用客户现在有的词，不发明新词。新词客户放不进脑子。
3. 关键差异点只写一个，写三个等于没写。
4. 替代品必须是客户认识的名字。

## 六、电梯测试
把定位陈述说给一个不熟悉你的人，两分钟内，对方能不能用一句话复述"你是给谁解决什么的、和谁不一样"。
复述不出来的原因通常是：目标客户太泛、品类是自创词、差异点太多、或者根本没说和谁比。
通过标准：三个不同的人复述出来的意思一致。

## 七、定位的四道工序
1. **陈述**：写出两句式。
2. **证据**：每句话配一个可验证的证据(参考客户名、伙伴名、数据)。
3. **传播**：按该段客户信的渠道传(实用主义者信行业分析师、行业媒体、同行会议，不信科技媒体)。
4. **反馈**：拿定位去测销售对话，客户第一反应是"哦你们是做X的"，X对不对。

## 八、常见错误
1. 拿功能列表当定位。
2. 定位语里堆三个以上形容词。
3. 用"领先""创新""一站式"这类谁都能说的词。
4. 不敢点名对手，结果客户自己找个更强的对手来比。
5. 早期市场的定位(颠覆、愿景)不改，直接拿去打实用主义者。
