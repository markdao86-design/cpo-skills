# 投放算账手册

骨架取自 AgriciDaniel/claude-ads（MIT，12 平台付费媒体运营）与 coreyhaines31/marketingskills，
数值口径换成 算力企业的 B2B 重资产业务。

**一条总纪律：永远不要在没有这三个数之前开投 —— 可承受 CPA 上限、盈亏平衡 ROAS、LTV:CAC。**

---

## 一、核心公式

```
CPM  = 花费 / 曝光 × 1000
CPC  = 花费 / 点击
CTR  = 点击 / 曝光
CPL  = 花费 / 线索数
CPA  = 花费 / 成交数
ROAS = 广告带来的收入 / 广告花费          ← 平台口径，会虚高
MER  = 总收入 / 总广告花费                ← 业务口径，最诚实
LTV  = 客户生命周期内的毛利贡献总额
CAC  = （广告花费 + 销售人力成本）/ 新客户数   ← 别漏掉人力
```

**盈亏平衡 ROAS = 1 / 毛利率**

毛利率 40% → 盈亏平衡 ROAS = 2.5。低于 2.5 的投放是在用现金换收入。

**可承受 CPA 上限 = 客户首期毛利贡献 × 可接受回收周期系数**

B2B 重资产业务允许回收周期长（6-18 个月），但必须**提前写死**，不能事后放宽。

---

## 二、三条账分开算，混算必出事

| 口径 | 看什么 | 特点 | 用途 |
|---|---|---|---|
| 平台口径 | 各平台自报 ROAS | **会互相抢功**，各平台加总常超过实际成交 | 只用于平台内部的素材与定向比较 |
| 业务口径 | MER = 总收入 / 总花费 | 不区分来源，但不会骗人 | 判断整体投放是否成立 |
| 现金口径 | 实际到账 - 实际付款 | 考虑账期、退款、坏账 | 判断现金流是否撑得住 |

**最典型的灾难**：各平台都报 ROAS 4.0，总账在亏。原因是同一笔成交被三个平台同时认领。

**检查动作**：把各平台自报的成交数加总，和 CRM 实际成交数对一遍。超出的部分就是重复归因。

---

## 三、归因口径先定死

上线前必须书面确定四件事：

1. **归因窗口**：点击后多少天内的成交算这次投放的（B2B 长周期建议 30-90 天）
2. **归因模型**：末次点击 / 首次点击 / 线性 / 时间衰减 —— 选一个，全程不换
3. **口径冲突怎么办**：平台口径和 CRM 口径不一致时，**以 CRM 为准**
4. **谁来对账**：固定一个人，固定一个频率

**换归因模型等于换计分规则，中途换会让所有历史对比失效。**

## 四、素材闭环

### 4.1 闭环结构

```
素材库 → 分配曝光 → 回收数据 → 低于淘汰线下架 → 补充新素材 → 回到素材库
```

### 4.2 四条硬规则

**规则一：淘汰线提前定死**

例：曝光达到最小样本量后，CTR 低于组内中位数 60%，或 CPA 高于上限 1.5 倍 → 下架。

数字可以调，但必须**跑之前就写下来**。事后定线等于为失败找理由。

**规则二：最小样本量不到不判死刑**

粗略判据：要判断转化率差异，每个素材至少要有 **100 次转化事件**量级才谈得上可信；
B2B 转化事件稀少时，用上层指标（CTR、落地页停留）做早期筛选，但不能用它定生死。

**杀得太早 = 在杀运气，不是在杀素材。**

**规则三：素材补充要排期**

素材是消耗品，衰减是必然的。排期做法：每周固定产出 N 组新素材进池，
不要等池子跑干了才想起来做。

**规则四：千人千面的前提是人群分得出来**

分不出人群的"个性化"只是随机发不同的话。
先问：我们能稳定区分出哪几类人？（矿主 / 机构 / 经销商 / 新手）
分不出来就先不做个性化，做分层投放。

### 4.3 素材衰减监控

同一素材的 CTR 连续下滑且频次（frequency）上升 → 受众疲劳，该换了，不是该加预算。

## 五、预算分配

### 5.1 三段法

| 段 | 占比参考 | 目的 | 判据 |
|---|---|---|---|
| 确定性投放 | 60-70% | 已验证有效的渠道与素材 | 稳定达到 CPA 目标 |
| 优化测试 | 20-30% | 已知渠道的新素材、新定向 | 跑出可比数据 |
| 探索 | 10% | 全新渠道 | 允许失败，但要记录 |

**探索那 10% 不能砍。** 砍掉之后你会在现有渠道衰减时无路可走。

### 5.2 加减预算的判据

- **加**：连续两个周期 CPA 低于上限，且规模未触及受众天花板
- **减**：CPA 连续两周期高于上限，或频次持续上升而转化下降
- **停**：MER 低于盈亏平衡，且两轮优化无改善

## 六、B2B 重资产业务的特殊性

重资产矿业企业不是电商，这几条要改：

1. **成交周期长**：归因窗口要拉长到 30-90 天，短窗口会让所有渠道看起来都无效
2. **成交数少**：统计显著性很难达到，要接受"用判断补数据"，但要说明这是判断不是结论
3. **线索质量 >> 线索数量**：优化目标不能设成表单提交数，要设成"合格线索"（见 `commercial-sales` 探需八问）
4. **人力成本占大头**：CAC 必须包含销售人力，否则会严重低估获客成本
5. **口碑渠道算不进平台口径**：矿圈大量成交来自转介绍，这部分不会出现在任何广告后台里，
   只看平台数据会低估品牌投入的价值

---

## 七、不许做的事

1. 不许在没有可承受 CPA 上限时开投
2. 不许中途更换归因模型后拿新旧数据做对比
3. 不许用平台自报 ROAS 向上汇报总体效果
4. 不许把"曝光量""互动量"当作主指标向上汇报
5. 不许编造缺失的财务输入；缺了就标明缺，不要用行业平均值假装有数
6. 不许只给点预测不给假设与敏感度
7. **彩票型产品（Solo / Team Mining）不进常规投放池**，渠道政策与地区准入先过法务
