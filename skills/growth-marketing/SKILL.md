# 首席增长官 / 营销品牌投放 Skill

服务对象：算力企业的增长与市场团队 + CEO 决策。
产出 = 可直接执行的增长动作 + 算得清的投放账 + 能落地的文案与品牌资产。

## 1. 增长诊断闸口（任何增长需求先过这三道，不许跳）

**最常见的错误是漏在底下，却在顶上倒水。**

### 闸口一：有没有 PMF

判据：**留存曲线会不会走平**。不走平就不是增长问题，是产品问题，获客花的每一分钱都在漏掉。

- 走平（Smiling / Flattening curve）→ 过闸，可以谈增长
- 持续下滑到零 → 停。先解决产品或客户匹配，不做任何投放

### 闸口二：漏在哪一层

按 AARRR 逐层算转化率，找**最低的那一层**，只修那一层。

| 层 | 问题形态 | 不该做的事 |
|---|---|---|
| 获客 | 没人知道 | —— |
| 激活 | 来了不动 | 继续加大投放（人更多，漏更快） |
| 留存 | 来了就走 | 发优惠券（买来的留存一停就没） |
| 变现 | 不付钱 | 降价（降完还是不付就只剩亏损） |
| 推荐 | 不带人 | 做裂变活动（没有满意用户的裂变是扰民） |

### 闸口三：是环还是漏斗

漏斗是线性的，倒进去多少出来多少；环是复利的，产出变成下一轮的投入。

**五型增长环**（出处 Brian Balfour / Reforge）：病毒环、使用环、协作环、UGC 环、推荐环。
重资产矿业企业现实里能成立的主要是**推荐环**（老矿主带新矿主）与**销售环**（赚的钱再投机位再带产能）。
不要硬套 C 端病毒环，矿圈没有分享欲，只有信任传递。

## 2. 增长模型与指标

### 2.1 北极星指标（矿圈版）

**不要抄 DAU。** 算力企业的客户一年登录十次都算活跃。

候选北极星，按业务线选一个主的：

| 业务线 | 北极星候选 | 为什么 |
|---|---|---|
| 托管 | **已签约并在架的 MW**（或机位填充率） | 直接对应收入，且反映交付能力 |
| 云算力 | **在存续期内的合约 TH 总量** | 比新签金额更能反映真实盘子 |
| 全公司 | **客户累计留存年数 × 规模** | 把"留得久"算进去，防止只冲新签 |

**判据三问**：这个数涨了客户是不是真的得到价值？它可测量可拆解吗？它涨了收入会不会跟着涨？
三问有一问答不了，就不是北极星。

### 2.2 指标树

北极星往下拆两层，每个叶子必须有人负责、有动作可做。
**叶子指标不能是"知名度"这种没人能动的东西。**

### 2.3 AARRR 基准（参考值，用来判断好坏，不是目标）

| 环节 | 指标 | 一般 | 好 |
|---|---|---|---|
| 获客 | 访问→注册 | 2-5% | 8%+ |
| 激活 | 注册→完成首次关键动作 | 20-40% | 50%+ |
| 留存 | 首期留存 | 25-40% | 50%+ |
| 变现 | 免费→付费 | 2-5% | 8%+ |
| 推荐 | 产生推荐的用户占比 | 5-10% | 20%+ |

**B2B 重资产业务（托管）不要直接套这张表**，它来自 SaaS 与消费产品。
用它做量级参照，真实基准要用自己三个月以上的数据重算。

## 3. 投放：先算账，再花钱

**完整算法与模板见 `references/投放算账手册.md`。**

### 3.1 花钱之前必须先有的三个数

1. **可承受 CPA 上限** = 客户毛利贡献 × 可接受回收周期 ÷ 转化率
2. **盈亏平衡 ROAS** = 1 ÷ 毛利率
3. **LTV : CAC** —— 低于 3:1 就不是增长，是买收入

**没有这三个数就开投，等于闭眼开车。**

### 3.2 归因口径，先定死再看数

- **平台归因**（Meta/Google 自己报的）会互相抢功，加起来经常超过实际成交数
- **平台口径、业务口径（MER = 总收入 ÷ 总广告花费）、现金口径**三条线要分开看，不要混算
- 混算最典型的灾难：各平台都说自己 ROAS 很好，总账在亏

### 3.3 素材闭环（老板要的那套）

```
素材库 → 按算法分配曝光 → 回收转化数据 → 低于淘汰线的下架 → 定期补新素材
```

四条硬规则：

1. **淘汰线提前定死**，不要事后找补。例：曝光够量后转化率低于基准 60% 的一律下架
2. **每个素材要跑到最小样本量才判死刑**，否则杀掉的是运气不是素材
3. **素材补充要排期**，不是等跑完了才想起来做。素材库是消耗品
4. **千人千面的前提是人群分得出来**。分不出人群的个性化只是随机发不同的话

### 3.4 投放与营销自动化必须打通

曝光 → 点击 → 注册 → KYC → 下单 → 续约，**一条链一个客户 ID 贯穿**。

打不通的代价：看不到触达之后的数据变化，就永远不知道该加预算还是该换素材。
技术实现（事件总线、客户事实层）转 `bitfufu-cto`。

## 4. 品牌：定位是减法

**完整工作法见 `references/品牌定位工作法.md`。**

### 4.1 定位五组件（April Dunford）

1. **竞争替代方案** —— 客户不买你会怎么办（往往是"自己建"或"什么都不做"）
2. **独特能力** —— 只有你有的东西
3. **价值** —— 这些能力带给客户什么结果
4. **最佳客户** —— 最在意这个价值的是谁
5. **市场品类** —— 把你放进哪个框里，客户立刻明白

### 4.2 Onlyness 测试（Marty Neumeier）

填这句话，填不出来就是没定位：

> 我们是唯一的 ______，提供 ______，给 ______，在 ______（场景），在 ______（时代背景下）。

### 4.3 品牌拒绝做什么

**定位最硬的部分不是"我们是什么"，是"我们不是什么"。**
一份没有"我们拒绝"段落的品牌文档，等于没定位。

算力企业的例子：我们不是理财平台、不做收益承诺、不做"快速致富"叙事。
这些"不"同时是品牌资产和合规护栏。

### 4.4 定位红旗

- 用了"领先""创新""一站式""赋能"这类词 → 换成具体的、可验证的
- 竞争替代方案写的是竞品公司名 → 多数时候真正的替代方案是"客户自己干"或"不干"
- 最佳客户写成"所有需要算力的人" → 等于没写

## 5. 营销文案

### 5.1 三条通用原则

1. **先给结论，再给证据** —— 客户不读说明书
2. **一屏只回答一个问题** —— 首屏不放黑话，不放换算单位，不放需要算的题
3. **把客户心里的问题替他问出来** —— 他最想问的那三个，页面直接答，答不了就说实话

### 5.2 三套口径，不要混在一个物料里

| 对象 | 关键词 | 强调 | 回避 |
|---|---|---|---|
| 客户 | 稳、陪、你的账 | 穿越周期、自有电场、每天记账 | 规模排名、融资、股价 |
| 投资人 | 规模、产能、留存 | 算力曲线、装机、续约率 | 业绩指引（前瞻性陈述风险） |
| 内部 | 我们扛过来了 | 熊市里的具体片段 | —— 不出公司，但它是前两套的素材来源 |

### 5.3 活动与周年传播

**周年不是用来纪念的，是用来收单的。** 任何活动页必须带转化出口，分受众给不同按钮。
活动类文案详细套路与检查单见 `references/营销文案与活动传播.md`。

## 6. 增长实验

### 6.1 实验设计五件事（缺一不做）

1. 假设怎么写：改 A 会让指标 B 变化，因为 C
2. **最小可检测效应**先定，样本量由它反推，不是开跑了再说
3. 主指标只有一个，护栏指标要有（防止主指标涨了别处塌了）
4. **跑多久提前写死**，到点才看
5. 失败条件先写：什么结果算这个假设死了

### 6.2 四个常见翻车

| 翻车 | 表现 | 怎么防 |
|---|---|---|
| 偷跑看数 | 天天看，一显著就停 | 到点才看，或用序贯检验 |
| 辛普森悖论 | 总体赢，分人群全输 | 分层看，别只看合计 |
| 虚荣指标 | 曝光涨了，钱没涨 | 主指标必须能折成钱 |
| 满分指标 | 目标写成 100% 或归零 | 满分即失效，改成可达且可证伪的 |

## 7. 合规红线（加密 + 上市公司双重约束）

**营销文案改得再好听，这一关过不了都是白搭。**

| # | 红线 | 检查动作 |
|---|---|---|
| 1 | 不承诺收益、不暗示收益、不做收益率换算 | 搜「收益」「回报」「年化」「赚」逐处确认 |
| 2 | 不做择时引导（现在是低点、机会难得） | 搜「低点」「机会」「现在正是」逐处确认 |
| 3 | 不含前瞻性陈述（会涨、预计、将达到） | 搜「将」「预计」「有望」逐处确认 |
| 4 | 不晒客户名称、持仓、收益，除非书面授权 | 授权件归档 |
| 5 | 不用绝对化表述（第一、最大、最强） | 有第三方来源并注明时点才可用 |
| 6 | 所有数字与 20-F / 6-K 等已披露文件一致 | IR 书面确认并留存 |
| 7 | 中英文版本口径一致 | 双版对照，英文同样过法务 |
| 8 | 面向非专业投资者的产品物料 | 发布前法务终审 |

第 1、2、3 条是云算力业务的性质红线。**踩了不是公关事故，是监管事故。**

**特别提醒**：客户历史产出类的个性化物料（如"你在我们这挖了多少"），
只能摆事实不能加判断，不标"你错过了多少"，不计算已实现收益，不暗示现在该买。
做法见 `references/营销文案与活动传播.md` 的对账单章节。

### 7.1 彩票型产品（Solo 挖矿 / Team Mining）营销专章

**Solo 与组团挖矿本质是彩票结构**：小概率、大回报、本金大概率归零。
它的营销红线比云算力**高一档，而且是三重叠加**：

| 风险面 | 为什么 | 底线 |
|---|---|---|
| **证券定性** | 集资 + 他人努力 + 收益预期 = Howey 三要素齐全 | 组团尤其危险，"共同出资共享收益"正中共同企业要件 |
| **博彩监管** | 付费参与 + 随机结果 + 奖金，在部分司法区直接落入 gambling 定义 | 地区准入必须先过法务，不是上线后再说 |
| **广告法与平台政策** | 多数广告平台禁止推广博彩型产品；中国广告法禁止对收益作保证性承诺 | 投放渠道要逐个确认政策，别投了才被封号 |

**文案六不准**（比通用红线更严）：

1. 不准出现「必赚」「稳赚」「躺赚」——你们已经写了，守住
2. **不准只展示中奖案例**。晒爆块必须同时说明概率与大概率不中的事实
3. 不准用「概率」暗示可控（如"提高中奖率""优化命中"）。概率由算力占比决定，服务不能改变数学期望
4. 不准把预计概率写成收益预期。**"预计概率"是数学量，不是回报承诺**，两者展示位置要分开
5. 不准用紧迫感话术催单（"仅剩 3 席""最后 2 小时"配合收益暗示 = 诱导性营销）
6. 不准面向非专业客户做自动化生命周期触达推送。**彩票型产品不进营销自动化的默认推送池**

**产品侧必须对齐的三件事**（不做到，营销无论怎么写都有风险）：

1. **期望值必须可自验** —— 用户能自己算出同等算力下的数学期望与池型无关，页面要支持这个验证
2. **不成团必须原路退款** —— 规则要写进订单条款，不是写在 FAQ
3. **分配口径可复核** —— 净奖励、矿池费、异常补偿、损失算力的处理，结果页必须可逐项核对

**适用人群闸口**：这类产品只对理解并接受本金归零风险的客户开放。
把它推给"纯理财型客户"（见 `commercial-sales` 客户分型第五类）是最高风险动作。

**落地动作**：任何 Solo / Team Mining 的文案、活动、投放，
一律走 `chief-legal-officer` 终审 + 地区准入确认，**不走常规营销审批流**。
